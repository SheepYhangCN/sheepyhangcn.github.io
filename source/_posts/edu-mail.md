我们学校加入企业微信就会获得一个 edu.cn 邮箱
这个东西在境外是堪比学信网的存在
可以在不少地方拿到教育优惠与白嫖

## Github 学生开发者包
首先需要在 Github 个人设置里绑定 edu 邮箱
进入[Github Education](https://education.github.com/)进行申请
注意不要开代理也不要开虚拟定位
学校输入自己学校的英文名
某些学校会强制要求有 edu 邮箱才能进入下一步，我的学校就是这样
没有要求 edu 邮箱的学校过审难度可能会更高

无论有没有 edu 邮箱，都需要提供证明
学生卡，录取通知书，成绩单，或者学信网截图都可以
我用的是录取通知书，直接上传照片就可以了
然后等待一段时间就会有邮件通知过审
需要等待三天（72 小时）才会解锁权益

如果被拒了可以尝试其它人的方法
用一张纸写上材料内容的英文翻译
然后和材料原件同框拍照上传
同时还要把 Github 的姓名设置成真实姓名
完成后再改回去

### 权益
三天后会发邮件到你的 edu 邮箱通知你权益已就绪
进入[Github Education](https://education.github.com/pack)查看有什么能吃

#### Github Pro & Copilot Student
[Copilot Student 兑换](https://github.com/github-copilot/free_signup)
Github Pro 应该在权益解锁后立刻生效
这两个均为两年有效，两年后再次认证可继续获得 

#### 第三方权益
翻到下面 All offers 即是第三方提供的权益
这里的权益全部都可以透过绑定 Github 授权来快速获取
而无需单独绑定 edu 邮箱单独申请
在这过程中也不强制需要使用 edu 邮箱注册

##### 三个域名免费一年
往下翻找到 `Namecheap` `.TECH` `Name.com` 这三个
Namecheap 可以开 `.me` 顶级域名
.TECH 可以开 `.tech` 顶级域名
Name.com 可以在 `.live` `.studio` `.software` `.app` `.dev` 顶级域名中选一个

注意 .TECH 与 Name.com 即使免费也需要绑定银行卡支付（0元）
注册好后关闭自动续费并删除支付方式即可

这三个域名都注册了，目前都只是 301 跳转 top 博客

##### JetBrains 学生订阅
往下翻找到 JetBrains
进入注册表单后选择「Github」进行连接认证
然后绑定现有的 JetBrains 账户或现场注册一个即可使用
订阅需要每年续期

##### Azure Education 与 100 USD 额度
Azure 有两个，一个是 18 周岁及以上的，一个是 13-17 周岁的
是 18 周岁及以上的这个才有 100 USD 额度
建议开浏览器无痕模式防止 Windows 自动登录
因为这里必须用 Github 登录

Github 登录后会提示绑定微软账户
注意出现多个邮箱账户时选择自己的那个，而不是 edu 邮箱
绑定好后就可以走 Github 授权学生认证来获得了

## JetBrains 单独申请
JetBrains 的教育优惠可以单独申请
在[表单](https://www.jetbrains.com/shop/eform/v2/students)选择「大学电子邮箱地址」即可
申请后绑定现有的 JetBrains 账户或现场注册一个
同样需要每年续期

## Notion 单独申请
可以参阅[官方文档](https://www.notion.com/zh-cn/help/notion-for-education)
简单来说只需要绑定自己的 edu 邮箱并设置为主邮箱
然后就可以在客户端的升级介面中看到按钮
注意不能把主邮箱改回来 否则会失去权益

对邮箱的硬性要求是学校必须被 [WHED](https://whed.net/home.php) 收录，否则是不行的
我学校就没有（怨念）

## Azure Education 单独申请
Azure 同样可以单独申请，但是比较麻烦
国内很多 edu 邮箱它是不认的，我的就是

进入[表单](https://signup.azure.com/studentverification) 填写姓名国家地区
注意学校名是可以不用填的
直接在邮箱填写 edu 邮箱

如果提交显示「你的电子邮件域当前未向我们注册。可以选择其他验证方法。」
说明你的邮箱不能用 只能用 Github 曲线救国了
要么也可以肘击微软客服让其人工给你处理，也是可以的
